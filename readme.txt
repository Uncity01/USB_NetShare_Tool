============================================
 USB 网络共享一键工具 - 使用说明
============================================

【这是什么】
本工具基于 adb（Android 调试桥），一键开启/关闭安卓手机的
USB 网络共享（USB 共享网络 / RNDIS），让电脑通过 USB 数据线
直接使用手机流量上网。
纯批处理脚本，绿色免安装，不编译 exe，不依赖 Python 等第三方
程序，不生成任何配置文件，不保存任何手机设备信息。

【文件清单】
  一键开启USB网络共享.bat          主程序，双击运行
  关闭USB网络共享.bat              关闭 USB 网络共享
  【可选】安装USB插入自动触发.bat  插入USB自动开启（需管理员）
  【可选】卸载USB插入自动触发.bat  卸载自动触发（需管理员）
  创建桌面快捷方式.vbs             双击生成桌面快捷方式

【首次使用前的准备（必须）】
1. 下载 adb 工具（platform-tools）：
   官方（需科学上网）：
     https://developer.android.com/tools/releases/platform-tools
   国内镜像：
     https://mirrors.tuna.tsinghua.edu.cn/Android/repository/platform-tools/
2. 解压后，把整个文件夹里的文件放到本目录的 adb 子文件夹内，
   确保 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 都在 adb\ 下。
3. 手机开启「开发者选项」：
   设置 → 关于手机 → 连续点击「版本号」7 次。
4. 打开「开发者选项」里的「USB 调试」和「USB 调试（安全设置）」
   （部分机型叫「允许通过USB调试修改权限」）。
5. 用数据线连接电脑，手机选择「文件传输 MTP」模式
   （不能选「仅充电」），保持屏幕解锁。
6. 手机首次连接会弹窗「允许 USB 调试吗」，
   请勾选「始终允许使用这台计算机」后点「允许」。

【使用方法】
双击「一键开启USB网络共享.bat」即可。
脚本会自动扫描所有已授权设备并执行开启，无需输入任何东西。
使用完毕，双击「关闭USB网络共享.bat」即可关闭。

【Windows 建议设置】
控制面板 → 电源选项 → 更改计划设置 → 更改高级电源设置
→ USB 设置 → USB 选择性暂停设置 → 禁用
避免 RNDIS 网卡被系统挂起。

【常见问题】
Q1：提示「未找到 adb.exe」？
A1：没有把 platform-tools 放到 adb 子文件夹，按上文准备步骤操作。
Q2：提示未检测到设备？
A2：检查数据线/换USB口、解锁屏幕、确认 USB 调试已开、
    USB 模式为文件传输、首次授权已允许；国产手机锁屏休眠会
    断开 adb，请保持亮屏。
Q3：开启了但电脑没网？
A3：等待几秒让系统识别 RNDIS 网卡；或重新插拔数据线；
    并确认已关闭电脑的「USB选择性暂停」。
Q4：多台手机同时插着？
A4：脚本会对所有已授权设备全部执行开启/关闭，属正常设计。
Q5：手机开了超级省电？
A5：超级省电会禁用 adb 调试，请关闭超级省电再使用。

【自动触发（可选）】
以管理员身份运行「【可选】安装USB插入自动触发.bat」，
之后插入 USB 设备会自动运行主程序。
注意：国产安卓锁屏休眠会切断 adb 通道；事件 ID 1006 主要针对
存储设备，手机 MTP 模式接入不一定触发，自动触发可靠性有限，
建议仍以手动双击运行为主。
