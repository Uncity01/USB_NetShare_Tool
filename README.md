# USB网络共享一键工具（USB_NetShare_Tool）

> 纯 Windows 批处理脚本，基于 adb（platform-tools）一键开启/关闭安卓手机 USB 网络共享（USB Tethering / RNDIS）。
> 绿色免安装、**不编译 exe、不依赖 Python 等任何第三方运行时**，双击即用。

## 功能特点

- **双击即用**：自动扫描所有已授权 adb 设备，无需输入序列号
- **多设备支持**：多台已授权安卓设备同时接入时，会对全部设备执行开启/关闭
- **命令降级**：优先命令执行失败自动降级备选命令
- **零配置零存储**：不生成任何 config 配置文件，不保存任何手机设备信息
- **完整排错提示**：未检测到设备时输出逐项排查指引
- **可选自动触发**：USB 插入自动运行（Windows 任务计划程序，事件 ID 1006）
- **纯原生 bat**：不使用 exe、Python 或任何第三方程序

## 目录结构

```
USB_NetShare_Tool/
├─ 一键开启USB网络共享.bat          # 主程序，双击运行
├─ 关闭USB网络共享.bat              # 关闭 USB 网络共享
├─ 【可选】安装USB插入自动触发.bat  # 创建计划任务（需管理员）
├─ 【可选】卸载USB插入自动触发.bat  # 删除计划任务（需管理员）

├─ 创建桌面快捷方式.vbs             # 双击生成桌面快捷方式

```

## 下载与部署

1. 下载本仓库 zip 并解压到任意目录（推荐 `D:\USB_NetShare_Tool`）
2. 下载 adb 工具（platform-tools）：
   - 官方（需科学上网）：<https://developer.android.com/tools/releases/platform-tools>
   - 国内镜像：<https://mirrors.tuna.tsinghua.edu.cn/Android/repository/platform-tools/>
3. 将 platform-tools 解压到 `adb\` 子文件夹内，确保 `adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll` 等文件直接在 `adb\` 下
4. 双击 `创建桌面快捷方式.vbs` 生成桌面快捷方式（可选）
5. 双击 `一键开启USB网络共享.bat` 开始使用

> ⚠️ **仓库不含 adb 二进制**（约 10MB+）。adb 工具需使用者自行下载放入 `adb\` 子文件夹，脚本启动时会自动校验，缺失则弹窗提示退出。

## 手机设置步骤（必须）

1. **开启开发者选项**：设置 → 关于手机 → 连续点击「版本号」7 次
2. **开启 USB 调试**：设置 → 开发者选项 → USB 调试
3. **开启 USB 调试（安全设置）**：部分机型叫「允许通过 USB 调试修改权限/模拟点击」
4. **USB 连接模式选择「文件传输 MTP」**：插线后下拉通知栏 → USB 连接方式 → 文件传输，**不能使用仅充电**
5. **首次连接授权**：手机弹窗勾选「始终允许此计算机」后再点「允许」；若误选拒绝，可在开发者选项 → 撤销 USB 调试授权后重新插拔
6. **保持屏幕解锁**，并在开发者选项中开启「不锁定屏幕」或「充电时保持屏幕唤醒」

## 使用教程

**开启**：双击 `一键开启USB网络共享.bat`，脚本自动扫描已授权设备并执行：

```
svc usb setFunctions rndis,adb            # 优先命令
service call connectivity 30 i32 1        # 失败自动降级
```

**关闭**：双击 `关闭USB网络共享.bat`，执行：

```
svc usb setFunctions none                 # 优先命令
service call connectivity 30 i32 0        # 失败自动降级
```

**自动触发（可选）**：
- 以**管理员身份**运行 `【可选】安装USB插入自动触发.bat`，创建计划任务（事件 ID 1006，USB 设备接入）
- 以**管理员身份**运行 `【可选】卸载USB插入自动触发.bat` 删除任务

## 故障排查

| 现象 | 排查项 |
| --- | --- |
| 提示未找到 adb.exe | platform-tools 未放入 `adb\` 子文件夹 |
| 提示 platform-tools 不完整 | 缺少 AdbWinApi.dll，需完整解压而非只复制 adb.exe |
| 未检测到设备 | 数据线/USB口、屏幕未解锁、USB 调试未开、MTP 模式、首次未授权 |
| 电脑识别到网卡但无法上网 | 等待几秒让系统识别 RNDIS 网卡；重新插拔数据线；关闭「USB选择性暂停」 |
| 开启后立即失效 | 手机锁屏休眠切断 adb；关闭超级省电模式 |

## 已知限制

- **锁屏休眠断连**：国产安卓系统锁屏/休眠会切断 adb 通道，锁屏状态下直接插数据线会识别失败，需解锁屏幕
- **超级省电禁用 adb**：手机超级省电模式会禁用 adb 调试功能，请关闭超级省电
- **多设备同开**：多台已授权设备同时接入时，脚本会对全部设备执行开启/关闭
- **自动触发可靠性有限**：事件 ID 1006 由「分区诊断」日志产生，主要针对 U 盘/移动硬盘等存储设备；手机以 MTP 模式接入不一定触发，建议以手动双击为主（备选：系统日志 Kernel-PnP 事件 2003）
- **USB 选择性暂停**：建议关闭 Windows 电源选项中的「USB 选择性暂停设置」，避免 RNDIS 网卡被系统挂起
- **adb 工具需自行下载**：仓库不包含任何 adb 二进制文件
